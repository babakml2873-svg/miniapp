# بازی کندل آگاه — مینی‌اپ تلگرام

یک بازی واکنش ۳۰ ثانیه‌ای برای تلگرام. کندل‌ها از چپ می‌آیند؛ وقتی هر کدام
دقیقاً روی خط وسط رسید، سبز را با فلش بالا و قرمز را با فلش پایین بزن.

کل اپ همین یک فایل `index.html` است — بدون بیلد و بدون وابستگی.
با هر push روی `main` خودکار روی GitHub Pages منتشر می‌شود.

بک‌اند جدول امتیازات (Telegram Serverless) و مستندات کامل در ریپوی اصلی،
زیر `miniapp/`.
